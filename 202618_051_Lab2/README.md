Project Details
This lab focuses on practicing vectorized programming with NumPy and data wrangling with Pandas. NumPy tasks include arrays, statistics, indexing, matrix operations, normal distribution, and visualization. Pandas tasks include data inspection, filtering, grouping, missing-value handling, outlier detection, feature creation, pivot tables, and data visualization using the Titanic dataset.

Key Observations
* Female passengers had a higher survival rate than male passengers.
* Higher passenger classes generally had higher survival rates.
* Fare was strongly related to passenger class.
* The Titanic dataset contained missing values, especially in the Age column.
* Fare outliers were identified using the IQR method.
* Survival rates varied across different Sex and Pclass groups.
